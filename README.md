### 🔭 A few things I've built

**[Predicting ICU Patient Survival](https://github.com/Kiana02/Predicting-ICU-Patient-Survival-with-Machine-Learning-Classification-Data-Analysis-)**
`Academic — solo project`
A model that predicts whether critically ill patients survive, trained on a real dataset of over 9,000 patients. I combined three different models into an ensemble and spent a lot of time making sure the evaluation was actually trustworthy, not just impressive-looking.
**Landed on 0.7559 Macro F1** on data the model hadn't seen — up from a ~0.49 baseline.
`Python` `scikit-learn` `Pandas` `NumPy`

**[Anomaly Segmentation for Autonomous Driving](https://github.com/Kiana02/Completed-MaskArchitectureAnomaly_CourseProject-Group35)**
`Academic — group project`
Worked with a team to compare two very different approaches to spotting things a self-driving car hasn't seen before — a lightweight segmenter versus a transformer-based model — across several datasets.
**Fine-tuning took our mIoU from 55.5 to 76.9**, and taught me a lot about how the metric you optimize for changes which model actually wins.
`Python` `PyTorch` `scikit-learn` `Pandas`

**[Conversational RAG Assistant](https://github.com/Kiana02/Build-RAG-Applications-IBM-Course-Assignment-)**
`Course assignment — from an IBM course on Coursera`
Built a small assistant that can answer questions about a private document — load it, chunk it, embed it, store it, and let an LLM answer from what it retrieves, with memory so follow-up questions still make sense.
`Python` `LangChain` `ChromaDB` `IBM watsonx.ai`
